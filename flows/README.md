
# Proyecto de Consolidación de Laboratorios - Node-RED

## Descripción

Este repositorio contiene el proyecto de consolidación de las prácticas desarrolladas durante el semestre académico utilizando Node-RED.

Se integran ejercicios relacionados con procesamiento de datos, monitoreo, comunicación MQTT, solicitudes HTTP, servicios REST y visualización mediante Dashboard 2.0.

## Laboratorios incluidos

1. Humedad y temperatura.
2. Clasificación de temperatura.
3. Componentes de Dashboard.
4. Sistema de alarmas con LED.
5. Gráficas con datos aleatorios.
6. Comunicación MQTT.
7. MQTT con Mosquitto e IoT.
8. Formulario y API de productos.
9. Solicitud HTTP POST.
10. Publicación de datos mediante MQTT.
11. Monitoreo de datos en Dashboard.
12. Cliente REST.
13. Servidor REST.

## Tecnologías utilizadas

- Node-RED.
- FlowFuse Dashboard 2.0.
- MQTT.
- Mosquitto.
- MQTTX.
- HTTP.
- API REST.
- Git y GitHub.

## Estructura del repositorio

- flows/: contiene la exportación JSON de los flujos de Node-RED.
- README.md: documentación del proyecto.

## Importación del proyecto

Para utilizar el proyecto:

1. Abrir Node-RED.
2. Seleccionar Import.
3. Cargar el archivo Consolidacion_NodeRED.json.
4. Instalar las dependencias necesarias si se solicitan.
5. Configurar las conexiones y credenciales correspondientes.
6. Realizar Deploy.
